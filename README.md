# Agency Poem Entry

Local entry for make.fun bounty `agency-poem-01` (`agency-poem-01`). The deterministic Node 22 program writes one original English poem to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (or `/output`).

Run locally:

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

No network, credentials, wallet, submission, or paid API is required or used.
